# Don't Look Back in Anger
Repository accompanying the paper:

***Don't Look Back in Anger: Wasserstein Distributionally Robust Optimization with Nonstationary&nbsp;Data***

## Paper Abstract
We study data-driven decision problems where historical observations are generated by a time-evolving distribution whose change over time is bounded in Wasserstein distance. We address this nonstationarity using a distributionally robust optimization model with an ambiguity set that is a Wasserstein ball centered at a *weighted* empirical distribution, thereby allowing for the time decay of past data in a way which accounts for the drift of the data-generating distribution. Our main technical contribution is a concentration bound for weighted empirical distributions that explicitly captures both the effective sample size (i.e., the equivalent number of equally weighted observations) and the distributional drift. Using our concentration bound, we select observation weights that optimally balance the effective sample size against the distributional drift of the data-generating process, taking into account the order of the Wasserstein ball. We also consider simple weighting schemes, and find that across a wide range of problem settings, a triangular weighting scheme is an effective choice that outperforms the classical weighting schemes of time windowing and simple exponential smoothing. Numerical experiments demonstrate the effectiveness of our&nbsp;approach.

## Description
This repository provides implementations of our numerical tests on a distributionally robust newsvendor problem with one or more items, solvers for observation weights that optimally balance the effective sample size against the distributional drift, a comparison of simple weighting schemes against these optimal weights, and a visualisation of the ambiguity sets of the weighted and intersection&nbsp;approaches.

## Dependencies
You must install a recent version of Julia from http://julialang.org/downloads/. The paper uses&nbsp;Julia&nbsp;1.12.

A number of Julia packages are required. They can be added by&nbsp;commanding:

`using Pkg;  Pkg.add.(["Distributions"; "StatsBase"; "JuMP"; "Ipopt"; "ProgressBars"; "Plots"; "Measures"; "CSV"])`.

## Reproducing Output from the Paper
You can reproduce the following figures by commanding the following from the repository&nbsp;folder:
- Figure&nbsp;1: `include("source/plot-ambiguity-sets.jl")`
- Figure&nbsp;2: `include("source/plot-weights.jl")`
- Figure&nbsp;3: `include("source/plot-worst-case-weighting-efficiencies.jl")`
- Figure&nbsp;4: `include("source/plot-train-and-test-single-item-drifting-newsvendor.jl")`
- Figure&nbsp;5: `include("source/plot-train-and-test-multi-item-triptych-drifting-newsvendor.jl")`

*Note that Figure&nbsp;4 relies on data generated by the script "generate-train-and-test-single-item-drifting-newsvendor-data.jl", and Figure&nbsp;5 relies on data generated by the script "generate-train-and-test-multi-item-triptych-drifting-newsvendor-data.jl" and processed by the script "process-train-and-test-multi-item-triptych-drifting-newsvendor-data.jl". The latter generating script is designed to run in a high-performance computing environment using the "generate-train-and-test-multi-item-triptych-drifting-newsvendor-data.pbs" job submission script and 300 jobs. Its data files are too large to host on&nbsp;GitHub.

The script `source/weights.jl` provides an implementation of an interior-point solver for computing observation weights that optimally balance the effective sample size against the distributional drift. For a Wasserstein distance order&nbsp;`p`, a number of historical observations&nbsp;`T`, a ratio of the drift bound to ambiguity ball size&nbsp;`ρ╱ε`, and a drift-profile exponent&nbsp;`η` (with `η = 1` for a linear drift profile and `η = 1/2` for a square-root drift profile), commanding `Wp_power_law_drift_profile_weights(p, T, ρ╱ε, η)` returns the optimal weights using the Ipopt solver. The script `source/plot-worst-case-weighting-efficiencies.jl` also computes the optimal weights without Ipopt, using their closed form for a given horizon and a line&nbsp;search.
